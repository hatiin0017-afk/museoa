# 키리 제목 레터링

표지의 **Kiri♡**를 영문 원형으로, **노래책**을 한글 원형으로 삼는다. 새 페이지 제목에는 아래 기준을 사용한다.

- **글자 뼈대**　획 끝은 둥글게 닫고, 한 음절 안의 가로획·세로획은 비슷한 굵기로 그린다. 받침과 ㅁ·ㅇ 안쪽의 빈 공간을 먼저 확보한다. 긴 제목은 전체 크기와 자간으로 맞추고 글자 폭은 유지한다.
- **테두리**　글자 높이를 100으로 두고 색 테두리 7, 바깥 흰 여백 6을 시작값으로 쓴다. 가까운 글자의 색 테두리는 붙여도 얼굴은 서로 구별돼야 한다. 하트가 붙는 제목은 글자와 같은 두께로 마감한다.
- **빛**　글자 면은 밝은 파스텔로 채우고 왼쪽 위에 작은 반사를 둔다. 색 테두리에는 위에서 아래로 이어지는 두 색만 쓴다. 흰 여백은 한 톤으로 둔다.

| 제목 | 테두리 위 | 테두리 아래 |
| --- | --- | --- |
| Kiri | `#69BDF2` | `#42A7E7` |
| 표지 하트 | `#C8B1FA` | `#AF93EC` |
| 상세 프로필 | `#618BDD` | `#466FC6` |
| 업보책 | `#20AAA1` | `#118C89` |
| 노래책 | `#8394E4` | `#687BCE` |
| 방송 일정 | `#F85D8C` | `#EA4578` |

새 제목의 벡터 윤곽은 [공통 SVG](assets/title-ink.svg)에 추가한다. 색은 페이지별로 지정하고 그라데이션 방향은 `#title-wash`를 상속한다. 페이지에는 제목을 읽을 수 있는 `h1`을 둔다. 940px와 320px 화면에서 받침, 흰 여백, 하트 꼬리가 서로 구분되는지 확인한다.

## 키리 팝 컬러 폰트

[설치용 TTF 다섯 색 받기](assets/KiriPop-ColorFonts.zip?v=1.001). 하늘, 파랑, 민트, 라일락, 연핑크를 각각 다른 글꼴로 설치할 수 있다. 다섯 글꼴 모두 현대 한글 완성형 11,172자, 기본 영문 대소문자, 숫자, 하트를 지원한다.

기존 제목에 쓰인 글자는 원본 레터링의 안쪽 윤곽을 쓴다. 이어서 입력하는 글자는 자음·모음·받침 조합으로 그린다. 바깥부터 흰 여백, 색 테두리, 파스텔 글자 면, 흰 하이라이트 순으로 겹친다. 색은 OpenType COLR/CPAL에 들어 있다. COLRv1에서는 그라데이션, COLRv0에서는 같은 계열의 단색 레이어가 표시된다. 컬러 폰트를 지원하지 않는 앱은 기본 글자 윤곽을 표시한다.

네브바는 파랑 **프로필**, 민트 **업보**, 라일락 **노래책**을 쓴다. 버튼용 WOFF2에는 해당 단어의 글자만 담고, 색 테두리를 47에서 33으로, 흰 여백을 38에서 17로 줄인다(1,000 UPM).

[제작 소스](../../tools/kiri-type/build.py). Python에 `fonttools`, `brotli`, `skia-pathops`를 설치하고 저장소 루트에서 `python tools/kiri-type/build.py`를 실행하면 설치용 묶음과 버튼용 웹폰트 세 개가 생성된다.

1.001에서는 ‘노’의 ㄴ과 ㅗ를 분리하고 ‘필’의 ㅍ 속공간과 받침 ㄹ의 획 간격을 넓혔다. ‘업’과 ‘보’의 글자 면은 각각 폭 690, 높이 740이며 좌우 여백도 같다(1,000 UPM).
