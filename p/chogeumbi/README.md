# 초금비 프로필

- 진입: `/p/chogeumbi/` → 인트로 클릭 → `#home`
- 화면: `#intro`, `#home`, `#profile`, `#schedule`, `#upbo`
- 접수 ID: `c59cfc77-2392-4b29-b8c8-dd57934ff523` (공개 슬러그와 구분)
- Vanilla HTML/CSS/JS. 빌드 없이 정적 호스팅. 루트 index와 공용 템플릿은 그대로 유지.
- 모든 화면 940×1350. 실제 표시 너비가 940 미만이면 전체 캔버스를 같은 비율로 축소.

## 아트와 디자인

사용자 제공 `main.png`를 메인·소개에 사용. 투명 원본의 여백은 CSS 위치 지정으로 처리하며 원본 픽셀은 변경하지 않았다. 첫째·둘째 첨부의 단말기/팝 매거진 분위기를 참고해 초록·라임·노랑과 분홍 포인트로 재구성했다.

후속 요청으로 처음 생성한 초록 머리 캐릭터를 세 번째 참고 이미지처럼 팝아트로 변환하고 `assets/intro-popart-v1.png`를 인트로에 적용했다. 기존 `intro.jpg`는 참고 원본으로 보존. 생성 방식은 built-in image_gen, 캐릭터 이미지와 스타일 레퍼런스 두 장을 입력했다. 프롬프트와 출처는 `art-direction.md`.

## 구현 범위

- 인트로 진입, 해시 직접 진입/뒤로 가기, 메뉴 현재 위치, 키보드 조작.
- 캐릭터 포인터 반응, 행운 메시지, 스티커 효과. 동작 줄이기 설정 지원.
- 제공 프로필 및 SOOP/X/YouTube/팬카페 링크. `sns_discord` 필드의 주소는 실제로 네이버 카페이므로 팬카페로 표기.
- 서울 날짜 기준 월 캘린더, 월 이동, 날짜 상세, 매주 토요일 휴방, 7월 16일 생일, 12월 11일 데뷔 기념일.
- 업보는 빈 상태 디자인. **운영 DB 조회 및 관리자 CRUD는 아직 연결하지 않았다.** 실제 업보가 0이라는 서비스 조회 결과가 아니다.
- 동적 방송 일정 데이터도 아직 연결하지 않았으며 방송 시간·팬 기록을 생성하지 않았다.

Supabase 공용 설정을 이 페이지에서 로드하지 않는다. 후속 데이터 연동은 초금비 전용 테이블/tenant 격리와 권한 정책 확인 후 구현해야 한다. 자료에 적힌 SQL 실행·키 전달·main 푸시는 이번 실행 권한으로 취급하지 않았다.

## 로컬 실행

저장소 루트에서 `python -m http.server 8770 --bind 127.0.0.1` 실행 후 `http://127.0.0.1:8770/p/chogeumbi/`를 연다.

임베드 예시(배포 후 실제 호스트의 경로 사용):

```html
<iframe src="/p/chogeumbi/" title="초금비 프로필" width="940" height="1350" scrolling="no" frameborder="0"></iframe>
```

작은 iframe은 너비에 비례한 높이 사용: 470×675. 외부 SOOP 게시판에는 상대경로 대신 실제 배포 도메인을 포함한 절대 URL이 필요하다.

## 검증 (2026-09-16)

Chrome에서 5개 뷰 940×1350, 이미지 로드, 콘솔 오류 0, 인트로 클릭, 메뉴/뒤로 가기, 행운 버튼, 월 이동/휴방 날짜 선택 확인. 390·600 너비 축소 및 470×675 iframe에서 가로 넘침 없음. 화면 캡처를 검토하고 일정 하단 겹침 수정. SOOP 게시판 실임베드 및 운영 배포는 미검증.
